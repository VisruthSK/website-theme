THIS CONTENT IS ENTIRELY LLM WRITTEN

This note uses every kind of content the theme sets, so that one page can show how they sit together. It is a short working document: a few paragraphs of prose with inline code in the line, a command such as pnpm exec astro build --root examples/full that has to wrap with the text around it, and a few notes in the margin.11 A note with inline code and a link to the Pagefind site⁠, set in the margin beside the line that mentions it.

Callouts, quotations and citations

Note (Callouts)

A callout can hold inline code, a link⁠ and more than one paragraph of text.

Tip (Quotations)

A block quotation keeps the body typeface and is set apart by its rule, as in this sentence from Wilde:

It was a large lovely garden, with soft green grass.

Citations are numbered in the order they first appear and link to the reference list at the foot of the page, as with the story quoted above [1]. A group takes one set of brackets [see 2; 3], and a locator can follow the key.33 A note with a long unbroken address that has to wrap instead of running out of the margin: https://example.com/stories/the-selfish-giant/chapter-one/paragraph-two/sentence-three⁠.

  • Lists keep the same measure and spacing as paragraphs.
  • Nested lists indent by a fixed step.
  1. Ordered lists number their items in the same colour as the text around them.
  2. The numbers are text, so they need the same contrast as text.
  3. A third item shows the numbers lining up.

Every one of these features can be switched off in theme.json, and the build then leaves no trace of it in the output. The second example site does exactly that, so it makes a useful comparison with this page: it has no margin notes, no maths and no citations, and its pages are correspondingly lighter.
